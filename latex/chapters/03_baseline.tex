\chapter{Establishing a Baseline}
\label{ch:baseline}

This chapter builds a solid MLP actor baseline for the IEEE 14-bus task.

\section{Evaluation Protocol}
\label{sec:results-evaluation-protocol}

All experiments use an 80/20 train/test chronic split. The 80\% training split is used for policy updates, while the 20\% test split measures how well the policy generalizes. Evaluation rollouts run periodically during training using 10 episodes per split. 
\\
\\
The main metric is test episodic survival (as a percentage): the fraction of
evaluation timesteps where the agent keeps the grid alive. Results are reported
as mean curves across seeds, with shaded regions showing the spread. Final
evaluations report the checkpoint with the highest test survival.

\section{IEEE 14-Bus Experiments}
\label{sec:bus14-results}

The initial MAPPO baseline from the MARL2Grid framework led to unstable policies
and low survival rates on the IEEE 14-bus topology-control task. The experiments
below test changes to the training and to the architecture, in order to build a
strong baseline.

\subsection{MLP Baseline}
\label{subsec:a0-core-reruns}

\paragraph{Question.}
Which changes are needed to get a stable MLP MAPPO baseline on the 14-bus
task?

\paragraph{Baseline and changes.}
We start from the MLP MAPPO baseline of the MARL2Grid framework and test several
main changes meant to stabilize training:

\begin{itemize}
  \item using reward normalization;
  \item changing the critic update so that the critic is updated once for the
  whole batch instead of once per agent;
  \item tuning the optimization hyperparameters to stabilize training, as
  summarized in Table~\ref{tab:new-hyperparameters}.
\end{itemize}

Table~\ref{tab:a0-core-summary} reports final and peak survival for the core
ablations. Figure~\ref{fig:rerun-a0-all} overlays all

\paragraph{Interpretation.}
The \texttt{Optimized MLP Baseline}, which combines reward normalization and an
optimized critic update, reaches the best performance and the fastest
convergence, with the highest and most stable final survival (\(\sim\)93\%).
Removing or reducing any of these three elements --- using a smaller
architecture, disabling reward normalization, or going back to a non-optimized
critic update --- lowers either learning speed or final survival. The original
unoptimized baseline fails entirely to learn a competitive policy. Because the
\texttt{Optimized MLP Baseline} consistently beats the ablations, it is used as
the reference for all later comparisons.

\subsection{Initial Do-Nothing Bias}
\label{subsec:a0-bias-reruns}

\paragraph{Question.}
Does biasing the initial policy toward action 0, the do-nothing action, help or
hurt learning? The idea makes sense: under normal conditions, human operators
usually leave the grid alone and take no action.

\paragraph{Baseline and changes.}
Our baseline uses no initial do-nothing bias in this rerun set. The bias
controls keep the same general protocol but change the initial probability mass
assigned to action 0.


\paragraph{Implementation detail.}
The bias is applied only at initialization: it changes the starting action
distribution before learning, without changing the reward, architecture, or PPO
objective. It is implemented by raising the initial pre-softmax logits of the do-nothing
action, so that the policy picks this safe action more often before any learning
update happens. This makes the ablation a test of exploration bias rather than a
test of model capacity.

\paragraph{Evidence.}
Table~\ref{tab:a0-bias-summary} and Figure~\ref{fig:rerun-a0-bias} compare the
zero-bias baseline with \texttt{Initial Bias 50\%} and
\texttt{Initial Bias 70\%}.

\paragraph{Interpretation.}
The effect of the action-0 bias is large, and a stronger bias is not simply
better or worse. The 0.5-bias curve remains unstable and well below the
zero-bias baseline, while the 0.7-bias curve eventually reaches the highest
final survival in this comparison. The current conclusion is that adding an
initialization bias is generally harmful or very unstable for the models.
Instead of helping exploration, a strong initial prior seems to stop the agent
from reliably finding a wide range of useful actions. It should be treated with
care as a main ablation variable.

\begin{tcolorbox}[colframe=red!75!black, colback=red!5!white, title=Chapter Summary]
\textbf{Objective:} Establish a stable, high-performing flat MAPPO baseline.
\\
\\
\textbf{Findings:}
\begin{itemize}
    \item \textbf{MLP optimization:} Hyperparameter tuning, reward normalization,
    and optimized critic updates raise the flat MLP baseline to roughly 93\%
    survival.
    \item \textbf{Do-nothing initialization:} The effect is large but goes in
    both directions; it is not a reliable substitute for learning when to
    intervene.
\end{itemize}
\vspace{0.35cm}
\textbf{Conclusion:} The tuned flat actor is a strong survival baseline. The
next step is to ask whether it can behave more like an operator by intervening
less often without losing that survival. That is the subject of
Chapter~\ref{ch:sparse-control}.
\end{tcolorbox}
