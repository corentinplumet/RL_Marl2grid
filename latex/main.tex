\chapter{GINE Architecture}
\label{app:gine-architecture}

This appendix will describe the GINE encoder used in the graph-based topology
control experiments. Building on the graph definition in
Section~\ref{sec:graph-representation}, the final version should specify the
message-passing layers, pooling/readout operation, and how the actor and critic
heads consume the encoded graph representation.

\chapter{Full-Test Checkpoint Registry}
\label{app:full-test-checkpoint-registry}

Table~\ref{tab:full-test-checkpoint-steps} reports the checkpoint step used for
each full-test result table. The values are the
\texttt{checkpoint\_global\_step} fields stored in the corresponding JSON files
under \texttt{Topology\_Task/outputs/full\_test\_eval}. The do-nothing policy has
no learned checkpoint. For the behavioral cloning students, the stored step is
the student checkpoint's optimizer-step count rather than a MAPPO environment
step.
