# Thesis LaTeX Plan

This folder starts the thesis as a LaTeX project, currently focused only on the
plan and chapter structure.

The outline is inspired by the referenced thesis structure:

```text
Introduction -> Background -> Environment -> Methods -> Results -> Discussion/Conclusion -> Appendices
```

For this project, the plan is adapted to decentralized MARL for Grid2Op topology
control, with sections for MAPPO baselines, graph encoders, rerun ablations, and
sparse intervention mechanisms.
